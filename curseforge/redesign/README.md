# CurseForge page assets (redesign)

Images for the redesigned CurseForge description of Disassembly Delight, by Renzo.
`description.md` references these files through raw.githubusercontent.com URLs.

- `header-*.png`: header banners for all six of Renzo's mods
- `card-*.png`: cross-promo cards for all six mods
- `footer-renzo.png`: footer brand banner
- `divider-disassembly-delight.png`, `badge-*-disassembly-delight.png`: section divider and link badges
- `media-*.png`: media section images

The images are drawn from the vanilla Minecraft, Farmer's Delight, Sophisticated Backpacks and Disassembly Delight textures.
